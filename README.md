# Md Saddam Hossain Khan — Trainer Website

Personal marketing site: AI & Capital Market Trainer for banks, financial institutions and universities.
Plain HTML/CSS/JS, so there's no build step. Hosted on GitHub Pages.

## Common edits
- **Add training photos:** put a photo in `assets/img/gallery/`, then in `index.html` find the matching tile in the "Training Highlights" section and set `data-img="assets/img/gallery/your-photo.jpg"`.
- **Change text:** edit `index.html` directly (GitHub → file → ✏️ pencil icon → Commit).
- **Colors/fonts:** variables at the top of `assets/css/style.css`.
- **Custom domain:** add a `CNAME` file containing your domain, update URLs in `index.html`, `robots.txt` and `sitemap.xml`, and point your DNS to GitHub Pages.
